# Notes de version — v2

Notes destinées au Play Store (champ "Nouveautés" lors de la création
d'une release). Limite Play Console : **500 caractères max** par locale.

Trois formats fournis par langue :
- **Court** : prêt à coller dans Play Console (≤ 500 caractères)
- **Long** : pour la description de l'app ou un changelog GitHub Release
- **Mini** : si tu veux rester très bref

---

## Français 🇫🇷

### Court (Play Console — 489 caractères)

```
Nouveautés de la v2

• Page Paramètres complète : thème (système/clair/sombre), son, retour
  haptique, affichage du bouton indice
• 3 modes de contrôle des erreurs : automatique, validation manuelle,
  ou sans vérification
• Statistiques : meilleur temps et nombre de parties résolues par
  difficulté
• Confirmation avant d'abandonner une partie en cours
• Meilleur support des lecteurs d'écran (accessibilité)
• Interface allégée et performances améliorées
```

### Long (description / changelog)

```
Sudoku v2 — la mise à jour la plus complète depuis le lancement.

Nouveautés
• Page Paramètres : thème système / clair / sombre, son et vibrations
  ajustables, possibilité de cacher le bouton indice.
• Contrôle des erreurs au choix : vérification automatique en temps
  réel, validation manuelle via un bouton dédié, ou aucune vérification
  jusqu'à la fin de la grille.
• Statistiques : meilleur temps et nombre de parties résolues, par
  niveau de difficulté.
• Confirmation avant d'abandonner une partie en cours pour éviter les
  pertes accidentelles.
• Accessibilité : annonces détaillées pour TalkBack (cellule
  sélectionnée, notes, erreurs, état des boutons).

Améliorations
• Interface épurée : icône Paramètres flottante en haut à droite,
  scrollbar masquée sur la page d'accueil.
• Sauvegarde automatique plus fiable et reprise de partie sans
  accroc, y compris après mise à jour.
• Génération de grilles Expert plus rapide.

Merci à toutes les personnes qui ont testé la v1 et fait remonter
leurs retours.
```

## English 🇬🇧

### Short (Play Console — 487 characters)

```
What's new in v2

• Full Settings page: theme (system/light/dark), sound, haptics,
  optional hint button
• 3 error-checking modes: automatic, manual validation, or none
  until the grid is complete
• Statistics: best time and number of games solved per difficulty
• Confirmation before abandoning an ongoing game
• Better screen reader support (accessibility)
• Cleaner interface and improved performance
```

### Long (description / changelog)

```
Sudoku v2 — the biggest update since launch.

New
• Settings page: system / light / dark theme, sound and haptics
  toggles, option to hide the hint button.
• Choose how errors are checked: live auto-check, manual validate
  button, or no check until the grid is full.
• Statistics: best time and games solved, broken down by difficulty.
• Confirmation prompt before abandoning a game in progress to
  prevent accidental losses.
• Accessibility: rich announcements for TalkBack (selected cell,
  notes, errors, button states).

Improvements
• Cleaner UI: floating Settings icon top-right, scrollbar hidden on
  the home screen.
• More reliable autosave and resume, even across updates.
• Faster generation of Expert grids.

Thanks to everyone who tested v1 and sent feedback.
```

```
v2 — Full settings (theme, sound, haptics), 3 error-checking modes,
per-difficulty stats, abandon confirmation, improved accessibility.
```
